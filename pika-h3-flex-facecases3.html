运行方法：使用官方 Pika H3 Flex 推理包 pika-h3-pro；按逐例记录的 task 执行 Ref2VA 或 T2VA，输出设为 768p，并启用 transformer CPU offload。模型采用六步采样，单条请求由一个 H200 GPU 进程执行；两路 worker 并行处理不同案例。

单条耗时是 metadata 中 assets、conditioning、transformer load、sampling、decode/encode 阶段耗时之和，包含条件准备、逐条模型装载、采样与编解码；不含启动器和排队时间，也不代表整批墙钟时间。单独完整进程端到端耗时：未记录。显存来自运行时按进程采样的 nvidia-smi used_memory；报告每条单卡进程峰值，没有合并两张卡。权重快照约由两个 transformer 变体 132.56 GB、文本编码器 66.72 GB、视频 VAE 10.42 GB、音频 VAE 0.61 GB、两种任务 adapter 5.53 GB及其他处理器/UI 文件 4.08 GB构成；该快照包含未同时加载的任务权重。
